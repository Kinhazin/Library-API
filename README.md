
# PROJETO SPRING-BOOT 

Este é um projeto desenvolvido como parte dos meus estudos.

O objetivo principal é **aprimorar minhas habilidades como desenvolvedor back-end**, replicando e explorando na prática conceitos avançados do ecossistema Spring Boot, incluindo:

- 🗄️ Persistência de dados com **JPA/Hibernate**
- 🌐 Construção de **APIs REST**
- 🔐 Autenticação e autorização com **JWT** e **OAuth2**
- 🐳 Containerização com **Docker**
- ☁️ Deploy e integração com serviços da **AWS**

> ⚠️ Este projeto tem fins **exclusivamente educacionais** e faz parte da minha jornada de aprendizado contínuo em desenvolvimento back-end. Algumas decisões de arquitetura e implementação seguem as práticas ensinadas no curso, com ajustes e experimentações pessoais ao longo do desenvolvimento.
